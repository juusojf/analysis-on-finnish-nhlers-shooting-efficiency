## Project Overview
This project investigates whether Finnish NHL players exhibit systematic zone-spesific shooting efficiency patterns relative to all other NHL players, using Expected Goals (xG) as the benchmark. The project uses regular season data from seasons 2022-2023, 2023-2024 and 2024-2025. 

This project doesn't look into individual Finnish players but rather investigates whether there is a structural nationality-level pattern among Finnish NHLers and how they convert goal-scoring opportunities from different shooting zones. If there is a clear pattern it carries direct implications for player development practices in Finnish ice hockey. 

There are two levels to this analysis:
- Do Finnish NHLers as a group over- or underperform the NHL population from certain shooting zones in efficiency by a statistically meaningful margin?
- If such patterns exist, what do they suggest about Finnish player development - and where should training emphasis be directed?
